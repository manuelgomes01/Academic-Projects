# Academic-Projects
Collection of programming assignments and academic projects completed during my Computer Engineering studies.
Practical assignments from the Algorithms and Data Structures course, covering data structure implementations in Go and low-level programming in C.


1) Abstract Data Types (ADTs) -  Go
Implemented stacks, queues, lists and dictionaries from scratch in Go. Each structure has a clear interface separated from its implementation. 
  - Practiced edge case handling (empty structures, resizing, invalid operations).
  - Analyzed time complexity for each implementation (amortized vs worst case).

2) Problem Solving with ADTs - Go
Created small programs that use the custom ADTs above to solve algorithmic problems, choosing the appropriate data structures for each problem.

3) Core Fundamentals - C
Implemented programs focused on correctness and clean structure. Worked with arrays, structs, input validation, pointer manipulation and error handling.  

4) Queue-Based File Management System - C
Implemented a file processing program in C that reads structured input, processes it using a queue and writes the result.
  - Handled dynamic memory manually (allocation and freeing).
  - Error handling for file operations and wrong input.
